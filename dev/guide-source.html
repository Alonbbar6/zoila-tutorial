Preparar tu computadora

1. Instala Power BI Desktop

  1. Abre la Microsoft Store, busca «Power BI Desktop» y pulsa Obtener. Es gratis.
  2. Ábrelo una vez para comprobar que funciona. Si te pide iniciar sesión, puedes cerrar esa ventana; no hace falta para practicar.

2. Instala Python

  1. Entra en python.org → Downloads → descarga la última versión para Windows.
  2. Al instalar, marca la casilla «Add python.exe to PATH» antes de pulsar «Install Now». Es muy importante.
  3. Abre el menú Inicio, escribe cmd y abre el Símbolo del sistema. Pega esta línea y pulsa Enter:
SÍMBOLO DEL SISTEMA
pip install pandas matplotlib

Esto instala dos «paquetes»: pandas (para trabajar con tablas) y matplotlib (para hacer gráficos). Power BI necesita los dos.

3. Conecta Python con Power BI

  1. En Power BI ve a Archivo → Opciones y configuración → Opciones.
  2. En la lista de la izquierda (sección Global) elige Scripts de Python.
  3. Comprueba que aparezca la carpeta donde se instaló Python. Si está vacía, elígela de la lista y pulsa Aceptar.

Etapa 1 Semana 1–2

Power BI sin código

Objetivo: entender cómo piensa Power BI antes de meter Python.

  1. En Power BI: Inicio → Obtener datos → Texto o CSV → elige ventas.csv → pulsa Transformar datos.
  2. Se abre Power Query (la «cocina» donde se limpian los datos). Revisa que la columna precio tenga números decimales (icono 1.2).
  3. Pulsa Cerrar y aplicar.
  4. Crea un gráfico de columnas agrupadas: arrastra producto al Eje X y cantidad al Eje Y.
  5. Añade una segmentación de datos con ciudad y prueba a filtrar.
  6. Crea tu primera medida: Inicio → Nueva medida y escribe:
DAX · medida
Total Ventas = SUMX(ventas, ventas[cantidad] * ventas[precio])

Ponla en un objeto visual de Tarjeta. Traducido al español: «recorre cada fila de la tabla ventas, multiplica cantidad por precio y suma todos los resultados».

¿Los precios salen multiplicados por 100 (250 en vez de 2.50)? Es por la configuración de tu país, que usa coma decimal. En Power Query, haz clic derecho en precio → Cambiar tipo → Usar configuración regional → Número decimal · Inglés (Estados Unidos).

Ejemplo 1: variables

hola.py
# Una línea que empieza con # es un comentario: Python la ignora
nombre = "Ana"          # guardo un texto en una "caja" llamada nombre
edad = 25               # guardo un número en otra caja

print("Hola,", nombre)   # print muestra algo en pantalla
print("El año que viene tendrás", edad + 1)

Ejemplo 2: listas, for e if

ventas_lista.py
ventas = [120, 80, 200, 150]   # una lista: varios números en una sola caja

total = sum(ventas)            # sum suma todos los números de la lista
print("Total vendido:", total)

# for = "para cada venta de la lista, haz lo siguiente"
for venta in ventas:
    if venta > 100:            # if = "solo si se cumple esto"
        print(venta, "es una venta grande")

Los espacios al principio de la línea importan. Así Python sabe qué está «dentro» del for y del if. Usa siempre 4 espacios.

Etapa 3 Semana 3–4

Tablas con pandas

Objetivo: hacer con Python lo mismo que hiciste en Power BI. Pandas es como «Excel con código».

Guarda este archivo en la misma carpeta que ventas.csv y ejecútalo con F5.

analisis.py
import pandas as pd                       # traigo la herramienta pandas y la llamo "pd"

tabla = pd.read_csv("ventas.csv")          # leo el archivo y lo guardo como tabla
print(tabla.head())                       # muestro las primeras 5 filas

# creo una columna nueva: total = cantidad × precio
tabla["total"] = tabla["cantidad"] * tabla["precio"]

# agrupo por producto y sumo el total de cada uno
por_producto = tabla.groupby("producto")["total"].sum()
print(por_producto)

  • Muestra solo las filas donde categoria sea «Bebidas».
  • Averigua cuál es el producto que más dinero ha generado.

Etapa 4 Semana 4–5

Python dentro de Power BI

Objetivo: unir las dos cosas. Hay tres lugares donde Power BI acepta Python.

A. Python como origen de datos

  1. Abre un archivo nuevo de Power BI: Inicio → Obtener datos → Más… → Otras → Script de Python.
  2. Pega este código. Cambia TuNombre por tu usuario de Windows. Truco: en el Explorador de archivos, haz Shift + clic derecho sobre ventas.csv → «Copiar como ruta de acceso».
Script de Python · origen de datos
import pandas as pd

# la r antes de las comillas evita problemas con las barras \ de Windows
ventas = pd.read_csv(r"C:\Users\TuNombre\Documents\curso\ventas.csv")

# preparo los datos antes de que lleguen a Power BI
ventas["total"] = ventas["cantidad"] * ventas["precio"]
  1. Pulsa Aceptar. Power BI te mostrará cada tabla que creaste en el código. Marca ventas y pulsa Cargar.

B. Transformar datos con Python en Power Query

  1. Inicio → Transformar datos → selecciona tu tabla → Transformar → Ejecutar script de Python.
  2. Power BI te entrega la tabla con el nombre dataset. Escribe:
Ejecutar script de Python · Power Query
# "dataset" es la tabla que Power BI me entrega automáticamente

# marco como "grande" cada venta de más de 10
dataset["es_grande"] = dataset["total"] > 10

# paso el nombre de la ciudad a MAYÚSCULAS
dataset["ciudad"] = dataset["ciudad"].str.upper()
  1. Aparece una pequeña tabla de resultados. Haz clic en la palabra Table junto a dataset.
  2. Si te pregunta por niveles de privacidad, para practicar con estos datos puedes marcar «Omitir comprobaciones de niveles de privacidad».

C. Un gráfico hecho con Python

  1. En el panel Visualizaciones, pulsa el icono Py y acepta Habilitar.
  2. Arrastra fecha, producto y total a «Valores».
  3. Abajo aparece el editor. Escribe esto y pulsa el botón ▶ (Ejecutar):
Objeto visual de Python
import matplotlib.pyplot as plt   # herramienta para dibujar gráficos

# sumo el total de cada producto
resumen = dataset.groupby("producto")["total"].sum()

resumen.plot(kind="bar", color="#F2C811")  # gráfico de barras amarillas
plt.title("Ventas por producto")             # título
plt.ylabel("Total")                           # nombre del eje vertical
plt.tight_layout()                            # acomoda para que no se corte
plt.show()                                    # ¡dibuja!

¿Por qué también arrastramos fecha? El objeto visual de Python elimina las filas repetidas. Si dos ventas tienen el mismo producto y el mismo total, contaría solo una. Añadir una columna que diferencie las filas evita ese error silencioso.

Reglas de oro para aprender con IA

  • Primero inténtalo tú. Dedica al menos 10 minutos a pelearte con el problema antes de pedir ayuda. Ahí es cuando más se aprende.
  • Pide pistas, no respuestas. Si la IA te lo resuelve todo, sentirás que aprendes, pero no podrás repetirlo sola.
  • Escribe el código a mano. Copiar y pegar es rápido, pero no se queda en la memoria.
  • La IA también se equivoca. Ejecuta siempre el código y comprueba que los números tienen sentido.
  • Nunca pegues datos privados. Ni contraseñas, ni datos de clientes, ni información de tu trabajo. Comparte solo los nombres de las columnas o datos inventados.
  • Explícalo con tus palabras. Al terminar cada sesión, escribe en una libreta 3 cosas que aprendiste.
Hecho con cariño para que aprendas a tu ritmo. Tu progreso se guarda solo en este navegador.
